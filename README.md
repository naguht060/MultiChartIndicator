# MultiChartIndicator
Multi chart indicator to analyse the stocks

## Run locally

From the project root, use one of these commands:

- `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_and_run.ps1`
- `powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1`

If the Microsoft Store Python shim is active, disable the App Execution Alias for `python.exe` and `python3.exe` in Windows Settings before rerunning.
